# 使用说明

## 开始学习

1. 在 Codex 中说明学习主题、要解决的实际问题和成功标准。
2. 按助手的引导回答问题、学习并尝试应用。
3. 在此笔记库中查看学习目标、资料、图示与有证据的学习记录。

正式答题在 Codex 中完成。HTML 小测用于练习；浏览或完成一堂课不会自动成为掌握证据。

## 自己的笔记

可以在 Obsidian 中添加笔记和编辑已有内容。助手会保护人工修改；发现冲突时会提示处理。
修改笔记不会自动向 Codex 发送消息。

## 备份

请一起备份数据目录下的“学习笔记库”、state 文件夹和 deployment.json。
state 保存待答题与工作流状态；只有笔记库的备份不能完整恢复学习进度。
